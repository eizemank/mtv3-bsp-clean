# mtv3-files — board-specific files (the "mini repo")

These are the files that are **unique to the mtv3 (Zarnitza RV1126) board**. They are kept
as real files (not patches) because they are new/standalone content, not edits to upstream
Firefly source. The directory mirrors the SDK tree, so they drop straight in:

```bash
cp -av mtv3-files/. <SDK_TOP>/
```

`apply.sh` does this automatically.

## Contents

| Path | What it is |
|------|------------|
| `buildroot/configs/rockchip_rv1126_rv1109_mtv3_defconfig` | board buildroot config (referenced by `RK_CFG_BUILDROOT`) |
| `device/rockchip/rv1126_rv1109/mtv3-rv1126.mk` | the board config (`./build.sh mtv3-rv1126.mk`) |
| `device/rockchip/rv1126_rv1109/parameter-mtv3.txt` | partition table |
| `device/rockchip/oem/oem_mtv3/*` | OEM rootfs scripts (RkLunch, aicamera, usb_config, …) |
| `kernel/arch/arm/boot/dts/rv1126-mtv3.dts` | kernel device tree |
| `kernel/arch/arm64/boot/dts/rockchip/rv1126_mtv3_*.dtsi`, `rv1126-mtv3.dts` | DT includes |
| `kernel/arch/arm/configs/rv1126_mtv3_defconfig` | kernel defconfig |
| `kernel/drivers/media/i2c/ov13850.c` | camera sensor driver (full file — overwrites upstream) |
| `u-boot/arch/arm/dts/rv1126-mtv3.dts` | u-boot device tree |
| `u-boot/arch/arm/dts/rv1126-u-boot.dtsi` | u-boot DT include (mtv3-customized — overwrites upstream) |
| `u-boot/arch/arm/dts/rv1126.dtsi` | u-boot SoC DT include — eMMC tuning tweak (full file, overwrites upstream) |
| `u-boot/configs/rv1126_mtv3_defconfig` | u-boot defconfig (`RK_UBOOT_DEFCONFIG=rv1126_mtv3`) |
| `rkbin/bin/rv11/rv1126_spl_mtv3.bin`, `rv1126_spl_v1.08.bin` | custom SPL loader blobs |
| `external/camera_engine_rkaiq/iqfiles/AVL_isp20/ov13850_OV13850-CAM1_default.xml` | OV13850 ISP tuning (IQ) file — not present in upstream Firefly |

> `ov13850.c`, `rv1126-u-boot.dtsi` and `rv1126.dtsi` are full-file copies that **replace**
> the upstream versions. They live here (not in a patch) on purpose; if you rebase onto a
> newer Firefly release, re-diff them against the new upstream.

## Integration glue (NOT in the patches, applied by apply.sh)

Two edits to shared upstream files are board-specific but cannot be standalone files. They
are applied as small explicit steps so the delta patches stay 100% mtv3-free:

1. **kernel** `arch/arm/boot/dts/Makefile` — register the DTB:
   ```make
   	rv1126-sphericalipc-ddr3-v10.dtb \
   	rv1126-mtv3.dtb \        # <-- add this line
   ```

2. **u-boot** `configs/rv1126_defconfig` — *intentionally left at upstream.* The original
   tree changed its `CONFIG_DEFAULT_DEVICE_TREE` to `rv1126-mtv3`, but the mtv3 build does
   not use that defconfig — it uses `rv1126_mtv3_defconfig` (which already targets
   `rv1126-mtv3`). The stray edit was dropped.

## Deliberately removed (not here, not in patches)

- `u-boot` `tee.bin.gz`, `tee.digest` — build artifacts (regenerated by the u-boot build).
- `u-boot` `arch/arm/mach-rockchip/spl.c` — a debug `puts()` print; reverted to upstream.
- `buildroot` `configs/firefly_*_defconfig` (9 files) — edits to Firefly's own board
  configs; reverted to upstream.
